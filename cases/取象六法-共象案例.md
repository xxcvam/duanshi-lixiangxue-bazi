出处：《盲派命理高级教程》6.1 共象原则。原书案例的叙述文字已重写，只保留四柱、结论与机制。

## C1 目盲之灾

```yaml
造: 坤
四柱: 丁酉 辛亥 乙酉 丁亥
大运: 壬子 癸丑 甲寅 乙卯 丙辰
已知: 三岁时因病双目失明
```

**机制**：时干丁火三线共象全中 —— 干支象丁为目睛；十神象丁对乙木是食神，食神主孔窍（目为七窍之一）；宫位象时柱主头面五官。三象交汇锁定「眼」。
**触发**：地支双亥，亥中壬水与丁合（丁壬合）且克丁，光明被夺。原局有象、待运岁引动，三岁应。

**考什么**：能不能同时走干支 / 十神 / 宫位三线，而不是只看「丁火＝眼睛」一句。

## C2 腿疾与眼患交替

```yaml
造: 坤
四柱: 庚寅 丁亥 辛酉 庚寅
大运: 丙戌 乙酉 甲申 癸未 壬午 辛巳
已知: 三十五岁后腿痛十年；转入辛巳运腿痛渐止，转患白内障、眼痛流泪
```

**机制**：年时双庚坐寅木绝地。庚金干支象为骨骼；对辛金为劫财，劫财主肢体腿脚；坐绝地＝行动不便；寅木主神经与疼痛。四象共指腿骨痛。
**延伸共象**：年时双寅，寅中藏丙，为「对称出现之火」。八字中对称之火（两丙、两丁、两午、两戌）可类象为眼。故癸未运（35 岁后）腿痛十年，入辛巳运金木交战、火气外透，腿止而眼病起。

**考什么**：①同一结构在不同运上「病位转移」——不是断错，是象在流转；②「对称之火为眼」这条冷规则。

## C3 岳母之象

```yaml
造: 乾
四柱: 庚戌 己卯 丙戌 庚寅
已知: 断其岳母与妻子关系最近
```

**机制**：年柱＝祖上长辈远方；年支戌中藏戊土食神。食神在时主小、在年主老，落年柱即转指女性长辈。又年支戌与日支（妻宫）戌同字，故这一女性长辈与妻子贴得最近 —— 定岳母。

**考什么**：十神含义随宫位翻转（食伤在时主小、在年主老）。

## C4 工作性质

```yaml
造: 乾
四柱: 壬子 癸丑 丙寅 戊戌
已知: 国家公务员，从事建筑设计
```

**机制**：日支寅为丙火长生，寅又为功曹、主官署（公门象）；寅对丙为偏印，印主单位文书；坐日支＝自身归属。三线共指「国家单位」。
**延伸**：时柱戊戌双食神，食神主作品构思；戌有建筑物之象；戊戌同柱同气（干与支同为土、同为食神），象不拆开看，合看即建筑设计。

**考什么**：干支象（寅＝公门）＋十神象（偏印＝单位）＋宫位象（日支＝自身环境）三线，再叠加同柱连体象。

## C5 刺绣厂车间主任

```yaml
造: 坤
四柱: 辛卯 辛丑 丙辰 甲午
已知: 刺绣厂车间主任
```

**机制**：辛金质软而尖，类象为针；丑为金库，有聚集成排之象，可视作机器群；辛从丑出、丙辛合日主，合即管理；月柱为工作环境宫。
**局象**：全局木火包 —— 木主柔曲为丝线布匹，午为丙之刃主光彩，卯午相破有「剪开、刺绣」的动态。合起来就是：用针（辛）在机器（丑）上，把丝线（木）绣成光彩图案（火）。

**考什么**：能不能从散字拼出一个完整劳动场景，而不是只报「辛金＝针」。

## C6 银行大员（孔祥熙造）

```yaml
造: 乾
四柱: 乙巳 戊子 癸卯 庚申
异版: 庚辰 乙酉 癸卯 庚申（原理相通）
已知: 中央银行行长
```

**机制**：卯申合。庚申为正印，印主权力机构文书；卯为食神，食神生财、为财源。印合食神＝权力机构在管运作财源。申金本有金融货币象。故断银行；庚申印星带权，断为大员。

**考什么**：把「合」读成「控制/运作」而不是「和好」；看懂「印合食伤」这个「管理机构管钱」的固定搭配。

## 使用方式

六例的正确率不看能否复述结论，看**能否在三线里至少命中两条**并说清缺席的那一条为什么缺席。只报单线结论视为不通过。
