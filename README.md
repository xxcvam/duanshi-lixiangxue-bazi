# 段氏理象学 · 盲派八字 SKILL

把段建业《盲派命理高级教程》的理法与取象，拆成一套可被 AI agent 直接调用的规则库。

不是命理教程，是**判盘执行手册**：每个文件里的每一条都写成「看到什么 → 判什么」，带成立条件、例外和出处节号。

底本是两本书：高级教程（网络整理本）提供体系骨架与取象六法，**《段氏理象学》（中国商业出版社 2011）印刷本作最终仲裁**——它经作者排版校对，两书打架时以它为准。15 个文件、424 条规则逐条对着 269 页全书核过一遍，翻案清单见 `R0`。

## 这套东西修了什么

市面上流传的盲派 skill 大多在三个地方出错，这套逐条改了：

| 常见说法 | 本库的写法 | 依据 |
|---|---|---|
| 「盲派不看旺衰」 | 泄秀成格要日主旺而有根；身弱财旺受困；日主太弱不受生则为母慈灭子 | 2.2 / 2.3 / 2.4 |
| 「制用效率：合制＝冲制＝刑制＞克制」 | 制分两层：先判制尽/半制，再判用哪种法；原书的二分是「合制·冲制·围制·穿制（且制得干净）」＞「克制·耗泄·制不尽」，**不是四个品种的名次** | 2.1 / 8.3 |
| 「冲开墓库就是制掉了」 | 开库只有**冲、刑**两条路；**穿不开库，穿是穿制**；**合是闭库**。开库与制用是两套坐标，不能混 | 5.3；《段氏理象学》印刷页 30–31、114–115 |
| 「层功论：0.5 层 / 1 层 / 2 层 / 3 层」 | 七条可加权项（制去用神 2、制去库 2、带象 1、统 1、入墓 1、包局 1、月令 0.5），**功量可以叠**——印刷本逐层实算到四层千亿；制用神要**连原神一起制掉**才给满两层 | 1.4；《段氏理象学》印刷页 86–88 |
| 「四生中气不算根（亥中甲、寅中丙、巳中庚、申中壬）」 | **段氏原书相反**：这四者正是该干的长生位，算根。根位表＝禄·刃·长生·墓·本气·四库余气 | 4.1 / 4.2 / 2.2 / 14.2 |
| 只讲理不讲象 | 取象六法单独成章（共象 / 合象 / 换象 / 带象 / 借象 / 局象），共象走「干支—宫位—十神」三线排查 | 6.1–6.6 |

## 安装

### Claude Code / Codex / 任何支持 SKILL.md 的 agent

```bash
git clone https://github.com/xxcvam/duanshi-lixiangxue-bazi.git
mkdir -p ~/.claude/skills
cp -r duanshi-lixiangxue-bazi ~/.claude/skills/
```

Windows：

```powershell
Copy-Item -Recurse .\duanshi-lixiangxue-bazi "$env:USERPROFILE\.claude\skills\"
```

### 直接当提示词用

把 `SKILL.md` 全文贴进 system prompt，再把命中的 `references/*.md` 附上。

## 用之前必须知道

1. **本库不排盘。** 需要外部给出四柱（年月日时干支）、性别、大运。给的盘错了，后面全错。
2. **本库不替代本人。** 涉及疾病、寿元、牢狱的结论，只作提示，不作断言。见 `R12` 末尾。
3. **段氏体系本身是经验体系。** 本库把原文的判据尽量写实了，但原文没写清的地方（尤其 6.x 部分取象法）已明确标注，不替作者补原创。
