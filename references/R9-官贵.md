## 一、官命成立的四条路径

**规则**：主路径——官杀与印星俱在。官杀主职务名位，印星主权柄单位；缺任一项，或为虚名，或止于吏员。
- 判据：官杀为用时须印星辅佐；官杀为忌时须印星化之、或食伤制之。
- 反例：只有官杀无印，纵有职务也无实权，作吏员、执行层断。
- 出处：[8.1]

**规则·第二路径（不必有官杀与印星）**：官杀印星全无，只要局象成、成得纯，同样可以官至厅级。这条是印刷本明写的，优先级高于上一条的排除法。
- 原文：「此造也看不出任何做功，然有水木伤官成局，局象也纯，并非发财之命，而是一位高官。曾任检察院检察长之职，官至厅级」（乾造 壬午 壬寅 癸卯 甲寅）。
- 同向第二例：张之洞 丁酉 戊申 戊申 戊午，「土金伤官成局，又非常纯粹，配印午火，故得重权」。
- 判据：伤官成局而纯粹（或配印）主重权；局象纯而气势不杂，即是有格。
- 反例：见到无官杀无印星就断「白身」，是本书第一例就翻车的读法。
- 出处：印刷页 118–120

**规则·第三路径（带象定官）**：印带杀帽而支通墓库，是真权的另一条路。
- 例：庚子 己卯 甲辰 己巳——年柱庚子为印带杀帽，印星子水表权力，子通辰墓，辰为权力之库，甲坐辰地，故拥有权力；局中卯、巳反是影响其权力的废神，故官职不大，长久任副县长。
- 判据：带象之支须通于墓，才作真权；不通墓只作名目。
- 出处：印刷页 119

**规则·第四路径（逐级相制）**：命局未成一方之势时，做功可以一层压一层形成金字塔式的权力结构。
- 原文：「命局没有形成一方之势，他的做功是通过一级一级相制形成金字塔形的权力结构。」
- 判据：这类盘不靠清浊与效率升级，靠「谁压住谁」的链长升级；链条断一节，权力就到顶。
- 出处：印刷页 87

**规则**：官杀与印星必须有根。虚透天干只主名气、荣誉，不作实权。
- 判据：地支见根＝落地之权、管理之职；虚透天干＝名声、头衔、荣誉。
- 判据·虚透的正确用法：虚透之官若在宾位合身，断名气大而非掌权。案例：甲午 丁卯 丁卯 壬寅，壬水官星虚透合丁，断为大律师、名气极大 [7.3 案例十]。
- 出处：[8.1]

**规则**：制化官杀之字须在日时主位，或与主位紧贴关联。
- 判据：做功字在主位＝自己掌权；做功字在宾位＝替他人做官、或自己发财而不掌权。
- 反例：宾位做功而格局极大者，财上可成、权上不显，不得因官星多即断官职高。
- 出处：[8.1]

**规则**：官命断法固定五步：一察有无（官杀印星有无、有根无根）→ 二定喜忌 → 三归格局 → 四判层次 → 五分行业 → 六推运程。
- 判据：跳过「有无有根」直接归格，是最常见的错法；虚透之字不能进格。
- 出处：[8.1]

## 二、八大官格：逐格成立判据

**规则**：八格不是并列选项，是「官杀为喜则配、为忌则制化」的八种落法。先判喜忌，再对格。

### 2.1 官杀配印格（化杀生身）

- 判据：七杀或正官强旺，有印星贴身化杀生身，印与日主亲近（远隔无功）。
- 判据·最佳结构：财生杀、杀生印、印生身，连续相生而无破格之物。
- 断法：文官、技术官僚、学院派领导；稳重、有靠山、得上级赏识、学历高。
- 失效：印星无力或隔位；财星坏印（最忌）。
- 案例：乾造 甲申 壬申 戊寅 丁巳——申金食神在宾位生杀，时柱丁巳正印贴身化杀，正处级，因食神在宾故带技术背景而非纯行政 [8.1 案例一]。
- 出处：[8.1]

### 2.2 伤官佩印格（印制伤官）

- 判据：伤官旺而泄身太过，有印星能制住伤官。
- 断法：学者型官员、纪检干部、文宣领导；能写能讲，印制伤使其不触规则。
- 失效：伤官太旺而印太弱（制不住）；印太重伤官被制死（才华尽失）——两者皆不成格。
- 禁忌：最怕财星破印。
- 案例：乾造 丁未 丁未 辛酉 戊子——戊土正印高透制子水食神、兼化双透之丁杀，火金组合七杀做功，地区公安局纪检书记 [8.1 案例三]。
- 出处：[8.1]

### 2.3 食神制杀格（以技服权）

- 判据：七杀强旺，食神紧贴制伏。
- 断法：武职、公检法、军队、工程技术领导；胆大心细、执行力强。
- 失效：制杀太过（杀弱食强）则无威；制杀不力（杀强食弱）则反受其害；怕枭神夺食。
- 案例：乾造 乙未 己丑 乙未 丙寅——未中丁火食神制丑中辛金七杀，时支寅木合年支未（控制羊刃库、兵众），公安局长 [8.1 案例四]。
- 出处：[8.1] [8.2]

### 2.4 伤官合杀格（以智取权）

- 判据：七杀为忌，有伤官合而制之，且合必须成功（丙辛合、丁壬合、戊癸合一类），伤官有力。
- 断法：检察官、纪检干部、外交官、谋士型官员；善周旋、以规则制衡对手。
- 失效：官星来破合 → 功败垂成。
- 案例：乾造 癸巳 丙辰 辛巳 戊子——丙辛合官、戊癸合去伤官、巳申合制官之原神，多重合制且制得干净，英国首相，早年执业律师 [8.1 案例六]。
- 出处：[8.1]

### 2.5 财星制印格（以财得权）

- 判据：印星过旺为忌、闭塞日主，有旺财星能制住印星。
- 前提（不可省）：此格一定是印为忌神；印为用神时财来制印即破格，主丢官。
- 断法：财政、金融、经济部门领导，国企高管；以掌控财权而得事权。
- 案例：乾造 戊辰 壬戌 癸巳 壬戌——戌土财库冲辰土劫财库，戊土正官合癸，财库制去劫库、官星合身管理，国务院总理 [8.1 案例八]。
- 出处：[8.1]

### 2.6 羊刃合杀格（以暴制暴）

- 判据：七杀强旺，羊刃与之相合或对抗并构成做功，且羊刃有根有力。
- 断法：军队将领、公安武警、一线执法官员；胆识过人、不畏艰险。
- 判据·弱制变格：羊刃弱而众杀强，以柔克刚者亦成，原文断为「温柔一刀」型（案例：乙巳 丙戌 庚午 辛巳，辛金羊刃敌众杀） [8.1 案例十]。
- 失效：羊刃无根（合不动杀）、羊刃无杀（寻常命）。
- 出处：[8.1] [8.2]

### 2.7 伤官去官格（伤官伤尽）

- 判据：官星为忌，伤官将其去得干净；官弱伤强方为妙。
- 断法：改革型官员、技术权威、纪检干部；不守旧规、敢破陈弊。
- 失效：官星为用而伤官见官 → 反为祸；运走财乡致官杀混杂 → 前程反复。
- 案例：乾造 甲申 壬申 戊申 己未——三申食神成势，时干己土劫财合去甲木七杀（甲己合化成功），合杀留食、伤官伤尽，官至县市级 [8.1 案例十一]。
- 出处：[8.1]

### 2.8 官杀配劫财格（劫财抗官）

- 判据：日主与比劫极旺成从强之势，官杀弱而被旺劫刃反克。
- 断法：开国元勋、革命领袖、草莽出身的大官；靠团队与群众力量推翻旧秩序。
- 失效：运逢财官破格 → 身名败裂。
- 案例：乾造 己未 癸酉 丁巳 丁未——火土成势，己土食神克癸杀、日时丁火劫财克酉金财（杀之原神），劫财去官杀，袁世凯 [8.1 案例十二]。
- 出处：[8.1]

## 三、公门与武职：看什么字分系统

**规则**：公门看寅，武职看戌；申酉为律法刀枪，丑为武库隐蔽，未为羊刃库。
- 判据·公门基础象：寅＝公门、官府、机关（甲寅、丙寅、戊寅做功有力者多在政府部门）；印配官杀＝公家单位任职；财库制印库＝管公家之财（财政、税务）。
- 判据·武职字：戌＝火库、枪弹库、武库；申酉＝刀枪兵器兼律法；丑＝金库、武库、隐蔽之所（公安、刑警、隐蔽战线）；巳午＝枪炮、灯光、能量；羊刃（卯、酉）＝刀枪暴力；七杀＝权威、暴力、压力。
- 判据·核心组合：火金相配（丙丁见申酉庚辛，尤巳申合、午酉破、丙辛合）→ 武职；金水成势见火来制 → 兵营或执法；比劫库（未）或羊刃库（辰）制印 → 掌军权或兵众之权；申酉丑寅交互 → 公安武警；伤官合杀、食神制杀 → 检察、纪委。
- 出处：[8.2]

### 3.1 军官的四类结构

- 判据①七杀配羊刃或羊刃库：杀入羊刃墓为典型军官象（卯木七杀入未，未既是戊土羊刃又是杀墓）；羊刃库冲刑杀库（未冲刑丑戌）同断。案例：己卯 辛未 戊辰 甲寅，少将、师级——关键在未土集羊刃与杀墓于一身 [8.2 案例一]。
- 判据②伤官制杀或制杀库：伤官为智慧技术，制伏七杀 → 技术兵种军官、参谋。案例：丁未 辛亥 己卯 甲戌，亥卯未三合杀局配时支戌土火库（枪弹库），部队副参谋长 [8.2 案例二]。
- 判据③官杀配比劫或比劫库：官杀管比劫＝管兵众；比劫库冲刑官杀库＝调动兵众。案例：辛卯 己亥 丙申 庚寅，金水成势，行火运制金水而得兵权，正师级 [8.2 案例三]。
- 判据④戌土火库做功：戌为火药库、刀枪库，在局中起关键作用即入军警。案例：辛巳 戊戌 己未 辛未，戌未刑开杀库，总后勤部正师级、官至大校 [8.2 案例四]。
- 出处：[8.2]

### 3.2 公安、法院检察、司法纪检的分野

**规则·公安（警察、武警）**：申酉丑寅组合做功；丑戌相刑（丑为阴库主犯罪隐蔽，戌为火库主正义，刑之象扫黑破案）；阳制阴（丙丁巳午戊戌 制 辛酉癸子丑）＝正义制邪恶。
- 反例：申丑本身是「牢狱组合」，必须再见寅（公门）与戊土（阳）制之，才反成公安，否则不作执法断。案例：戊申 丙辰 乙丑 戊寅，寅木与戊土包制申辰丑，公安机关处级 [8.2 案例五]。
- 出处：[8.2]

**规则·法院、检察院**：申酉金做功为法检本象；伤官合杀＝检察官、纪检（伤官主检查、揭露、辩论）；食神制官＝法官（食神主条文）；卯酉冲、卯午破＝依律断案与辩护。
- 案例：丙午 乙卯 甲申 甲戌——丙午伤官围制申金正官，卯午破主法律条文，被制之官合到主位，最高人民法院副院长 [8.2 案例七]。
- 判据·辅助：羊刃合杀兼统财者，可断管财的法官（法院经济庭庭长，壬子 丙午 壬辰 丙午） [8.2 案例八]。
- 出处：[8.2]

**规则·司法、纪检**：伤官重或伤官见官＝监督官员；枭神夺食＝查处经济问题（纪检、审计）。
- 反例：同为「火土制金水」，制酉金印星断刑警抓捕，制食神断查账，须看被制之字是印还是食伤。
- 出处：[8.2]

### 3.3 文武兼象（政委型）

**规则**：有武职象（比劫库制印）而又有食伤、印星泄化羊刃七杀者，断军队文官。
- 判据：武职字仍在（未穿子掌军权），但刀枪库被合闭（午未合）、且木火主文。
- 案例：乙未 壬午 甲子 甲戌——未穿子为掌军权象，然午未合闭刀枪库、午为伤官木火主文，军队政委而非持枪武将 [8.2 案例十]。
- 出处：[8.2]

### 3.4 多象定一象

**规则**：一造兼具多象时，取最有力、最贴切的做功点定系统，其余作兼象。
- 判据：看哪一个组合做功最重、最贴主位。案例：戊申 丙辰 乙丑 戊寅 兼有申丑（司法）与寅戊（阳制阴）两象，最终以阳制阴定公安 [8.2 案例五]。
- 出处：[8.2]

## 四、官职层次：三条判据

**规则**：层次由三项定：格局清浊、做功效率、制化程度。官星有无不参与定层次。
- 出处：[8.3]

**规则·清浊**：清者贵，浊者贱。
- 判据·清格：官印相生、杀印相生、伤官佩印、食神制杀等配置纯粹；无财星坏印、无伤官见官、无官杀混杂。
- 判据·浊格：官杀混杂、财星坏印、伤官见官、用神互战。
- 断法：清格心性端正、仕途顺畅、易得高位；浊格心性多欲、仕途多阻、官职难高。
- 案例·清：癸未 乙卯 戊寅 丙辰——财生官、官生印、印生身连续相生，官印俱透无破格物，部级高官 [8.3 案例一]。
- 案例·浊：癸卯 乙卯 戊寅 乙卯——三卯双乙夹日，官杀混杂极旺攻身，印藏寅中被泄无力化杀，日主无依，高位截瘫，作灾命不作官命 [8.3 案例二]。
- 出处：[8.3]

**规则·做功效率**：制得越干净、捕神越成党，权越大。
- 判据·高效率：合制、冲制、围制、穿制，且制得彻底；贼神孤立无援，捕神成党成势。
- 判据·低效率：克制、耗泄，或制而不尽、反反复复；贼捕力量相当、互相纠缠。
- 判据·围制为最高：把官星连同其库包围制尽，主最高权柄（案例：丙戌 庚寅 乙丑 丙子，丑官杀库被火土包围无处可逃，国家总统） [8.3 案例四]。
- 判据·捕多贼少亦为低效：伤官双透而官星只一且有微根，制之不尽，止于处级 [8.3 案例五]。
- 出处：[8.3]

**规则·制化程度**：深者权专，浅者权泛。
- 判据·深：用神直接彻底制住核心忌神（禄合官、官坐禄自合）→ 权力来源清晰、职责明确、权力集中。
- 判据·浅：用神通过生、泄间接影响忌神，或忌神有多个源头 → 权力来自平台，非直接行政权。
- 案例：辛丑 庚寅 丙辰 癸巳——癸巳自合、禄合官，自己直接控制官星，公安局长（处级） [8.3 案例六]。
- 案例：乙巳 辛巳 辛卯 甲午——财旺生官，自己合财、财去生官，权力由企业平台而来，国企副总（副厅级） [8.3 案例七]。
- 出处：[8.3]

**规则·与层功论对接**：层功论的七项加权（见 R1：制去用神 2、制去库 2、带象 1、统 1、墓库 1、包局 1、月令 0.5）在官命里主要落在「制尽 / 包局 / 带象」三项上；制尽且包局者对应最高层，制不尽者落在低层。

## 五、权力得失应期：五条法则

**规则**：应期只在命局关键处被运岁引动时成立，不看吉凶星曜。
- 出处：[8.3]

**规则·合动**：原局有合（六合、三合、暗合、干合），逢大运流年冲此合为应期。
- 案例：戊戌 癸亥 辛卯 辛卯——日时双卯合年支戌，行戊辰运辰冲戌冲动原局之合，官职连升，由国企副总至副厅 [8.3 案例八]。
- 出处：[8.3]

**规则·冲动**：原局有冲（六冲、相破），逢大运流年合住相冲之一方为应期。
- 案例：甲辰 丙寅 庚申 乙酉——原局寅申冲禄，行癸亥运亥合寅，解冲而得调动并提升 [8.3 案例九]。
- 出处：[8.3]

**规则·墓库**：原局有墓库，逢运岁刑冲穿开库，或引动入墓之物为应期，主收藏、汇聚、掌权之事发生。
- 案例：壬子 壬寅 庚辰 辛巳——官杀库戌原局不见（作象看），行辰运辰冲戌开库，开始掌实权并连升 [8.3 案例十]。
- 出处：[8.3]

**规则·穿害**：宾位用神穿主位之体 → 主得不到、受伤；主位之体穿宾位用神 → 可能得到，但过程激烈。
- 案例：庚子 己卯 甲辰 己巳——壬午、癸未运，午冲子、未穿子，把宾位印星制住，癸未年升常务副县长；同一穿亦主母亲健康或单位内部压力，得失并存 [8.3 案例十一]。
- 出处：[8.3]

**规则·十神到位**：用神（或制忌之字）在运岁出现、得根、旺相主升迁；忌神出现得根旺相而无制化主贬黜。
- 判据·凶的加强形式：忌神得长生而用神临绝地，为大凶之应。案例：庚午 乙酉 庚子 壬午（和珅），行庚寅运寅为午火官星长生、庚金绝于寅，制官之局反局，革职抄家 [8.3 案例十三]。
- 出处：[8.3]

**规则·两类结构专项**：过河拆桥格喜行制去「桥」（印、官）之运，拆桥之时即得权之日；贼捕结构喜行贼神之运，贼出现正好被制，功业大成。
- 出处：[8.3]

## 判错清单

- 见官星即断官命：虚透无根只主名气；官杀混杂无制而日主无依，是灾命不是官命。
- 印为用神却用财去制印：财星制印格的前提是印为忌，印为用则财制印＝破格丢官。
- 制不尽当成制得干净：制不尽在官上是低效（官小），在财上反而是大财（见 R8），先分清问官还是问财。
- 只按「申酉＝法院」断系统：申丑本身是牢狱组合，须再见寅与阳制才转公安；被制之字是印、是食伤、是官，断出的系统各不相同。
- 把「官命必须有官杀与印星」当铁律：印刷本第一例壬午 壬寅 癸卯 甲寅，官杀印星全无，伤官成局而成厅级高官。缺官缺印不等于白身，先看局象纯不纯。
- 把功层的品级刻度当成精确换算：三套刻度本身不一致，且书里「四层」与「四到五层」互斥，只能给区间。
