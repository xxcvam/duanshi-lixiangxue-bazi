# R13 大运流年应期

> 覆盖节号：12.1、12.2、12.3、12.4、13.1、13.2、13.3
> 加载时机：原局结构与做功已定，需要回答「何时应事、应在哪一年、是吉是凶」时加载。

## 一、三层分工：谁定方向，谁定应期

**规则**：八字定贵贱层次，大运定十年顺逆，流年只定应期时点。三者不可互相代答。
- 判据：原局做功组合决定上限；大运只回答「这十年顺不顺」；流年只回答「哪一年动」。
- 反例：拿「流年干支是喜用就吉」直接定吉凶——原文明确点此为误区。流年之字是喜是忌要放回原局做功里看，不是查喜用表。
- 出处：[13.1]

**规则**：四柱分限，每柱管一段年龄，该柱即该阶段的「主事星」。
- 年柱 1–18 岁（另有 1–15、1–16 两说，遇争年界时以断事需要择一，不混用）；
- 月柱 18–35 岁；日柱 35–55 岁；时柱 55 岁以后。
- 判据：该阶段之事，先看该柱之星与宫是否被坏，再看运岁是否引动该柱。
- 出处：[12.1]

**规则**：限与运吉凶相反时用交脱诀，两股力量分段生效。
- 限吉运凶：吉限内遇凶运，运内受挫，运过之后吉限之力复回。
- 限凶运吉：吉运未到而凶限之凶已先发动，吉运过后凶又再现。
- 限运两吉应吉，两凶应凶；一吉一凶则减力，不作纯吉纯凶断。
- 出处：[12.1]

**规则**：大限所属之字，在流年「反客为主」出现（含其禄神、原身），或逢冲合刑穿墓破，即为该限之事落地的应期。
- 判据：流年干支中出现该限柱的天干或地支 → 出现为应；流年冲合该限柱 → 引动为应。
- 出处：[12.1] [12.3]

## 二、大运的三种作用

**规则**：大运只有三种职能——引发、兑现、反局。
- 引发：运字冲、合、刑、穿、墓、破原局某字，把原局埋着的结构点着。
- 兑现：运字正是原局某字的原身透干、或该字之禄神临支、或该字原样重现。兑现是「事真的来了」，不只是「有动静」。
- 反局：运的走势与原局做功意向相反，最凶。反局时运过可复原，但运中之灾已经成立，不会因运过而消失。
- 出处：[12.2]

**规则**：引发要按「四待」找条件，不能凭空断动。
- 有合待冲（原局合住，等运岁来冲开）、有冲待合（原局冲开，等运岁来合住）、有墓待冲（吉神凶神入墓，等冲开）、有绝待生（原局某字临绝，等运岁来生扶）。
- 判据：先确认原局确实存在该「待」，再看运岁是否提供了对应的「冲/合/生」。缺前者则不断。
- 出处：[12.2]

**规则**：反局分三型，判法各不相同。
- 冲合反局：原局靠合来制，运来冲坏这个合 → 制力失效。
- 合冲反局：原局靠冲来制，运来合住 → 冲力被解。
- 战局：身弱者得运助有了根，硬抗旺神 → 抗得越久伤得越重。
- 出处：[12.2] [13.3]

**规则**：判「运字到位」用原身/禄神对照表，逐干查。
- 甲→寅、亥｜乙→卯、辰、未｜丙→寅、巳｜丁→午、戌、未｜戊→巳、戌、辰
- 己→午、未、丑｜庚→申｜辛→酉、丑｜壬→亥、申｜癸→子、辰、丑
- 判据：运或流年出现表中某支，即该天干「到位」，该天干所主之事进入可应状态。
- 出处：[12.2] [12.4]

## 三、大运分看还是统看（13.1 关键操作）

**规则**：常规大运上下五年分看——天干管前五年，地支管后五年。
- 判据：无特殊触发时一律分看。
- 出处：[13.1]

**规则**：出现下列任一情况，该运改作十年统看，不再切分：
1. 流年与该大运**天干五合**（甲己、乙庚、丙辛、丁壬、戊癸）；
2. 流年与该大运**地支相冲**（子午、丑未、寅申、卯酉、辰戌、巳亥）；
3. 该运干支一气（如丙午、戊辰、丁巳之类同气），本身不可分割。
- 判据：统看时，运的干支作为一个整体与原局作用，断事按十年一整段，不设前后半段落差。
- 反例：干支异气而当统看之年仍强行分看，会把「前五年发、后五年败」误断成「一直发」或「一直败」。
- 出处：[13.1]

## 四、流年三法：怎么把事落到某一年

**规则**：流年断应期只有三条路，逐条走完再定年。
1. **出现为应**：流年干支中出现原局某关键字的原字、原身或禄神 → 该字之事在该年落地。
2. **引动为应**：流年冲、合、刑、穿原局某字 → 该字之事被引动。
3. **干支互应**：流年干透出＝原局某地支的藏干透出 → 该地支之事被引动；流年支出现＝原局某天干的禄神或根气 → 该天干之事被引动。此为最细一层，用于在原局同柱多字时锁定具体是哪一位。
- 判据：三法指向同一字 → 该年应期确定，力度最大；三法指向不同字 → 各自独立成事，分别断，不合并。
- 反例：只有流年出现某字、原局却无该字之根无该字之事 → 只是过路之字，不必断。
- 出处：[12.3] [12.4]

**规则**：合的四种含义必须分开断，混用会判反。
- 合留：旺神被合住不动 → 留住，主成婚、定约、事定下来。
- 合动：被合之字由静转动 → 主变动、出行、启动。
- 合去：衰神被合走 → 主失去、离去、人走。
- 合绊：用神被合住使不上力 → 主事情受阻、拖延、被牵制。
- 口诀：「合处逢冲冲为应，冲处逢合合为期。」（≤20 字，[12.3]）
- 出处：[12.3]

**规则**：冲的五种含义按被冲之字的强弱分。
- 旺者被冲 → 冲动，主变迁、调动、迁移。
- 墓库被冲 → 冲开，主发（财库开则发财，官库开则得权）。
- 衰者被冲 → 冲去，主离去、失掉。
- 衰极被冲 → 冲破，主死亡、终结。
- 旺用神被冲 → 反吉（冲起用神，力量更显）。
- 出处：[12.3]

**规则**：刑、穿、破、墓各有专主，不能一律当作「冲」处理。
- 三刑只有两组：寅巳申、丑未戌。**子卯不是刑，是相破**（印刷本原话「其他书中所言子卯相刑，其实是相破」，印刷页 34）；「辰午酉亥自刑」印刷本无此说，本库不采用。
- 三刑的用法**近于六冲**，不表示刑法、罪恶与疾病（印刷页 34）——主变动、冲动、交换，不是「刑＝凶病」。
- 六穿为暗箭，伤人于不觉：子未、丑午、寅巳、卯辰、申亥、酉戌。其中能作**制**用的只有酉戌、卯辰、子未、丑午四组；申亥、寅巳相生，不作制用。
- 六破主暗中破坏、事从中断。
- 墓：**凡遇墓者都喜冲而开墓**（印刷本原文），开库另加一层功；关键不在开不开，而在开了之后里面的东西制不制得住——制得住＝得功发富，制不住＝忌神出笼为祸（印刷页 30–31）。
- 出处：[12.3] 印刷页 30–31、34

## 五、干支虚实与「填实」判据（12.4 核心）

**规则**：先判每个天干是实是虚，虚实决定该字是「能成事」还是「只是个信号」。
- 实：天干坐支有根有生（如甲寅、甲辰、甲子；丙午、丙寅、丙戌；戊午、戊戌、戊辰），或地支本气透干且得助。
- 虚：天干坐支无根无生（如甲申、甲戌、甲午；丙子、丙申、丙辰；戊子、戊申、戊寅）。
- 出处：[12.4]

**规则**：实神出现，事显而力强；虚神出现，事微，多数时候只是应期信号而非实事。
- 判据：一个虚透之字在运岁出现，只能断「此年有此一议」，不能断「此年大事成/大祸临」。
- 出处：[12.4]

**规则**：虚透之字要「填实」才真应事。填实的判据只三条，满足任一即是：
1. 运岁之支正是该天干的禄神或原身（查第二节对照表）；
2. 运岁之支是该天干的同类实根（同五行、本气、且不被冲克）；
3. 该字原局藏于某地支，运岁透出该藏干（干支互应），使藏者显形。
- 判据：填实之后，该字由「有其心无其力」转为「能实事」，原局中依附于它的结构（所生、所制、所合）一并启动。
- 出处：[12.4]

**规则**：填实本身中性，吉凶只看被填实之字是喜用还是忌仇。
- 喜用虚透：本是「有心无力」，运岁填实则事成。
- 忌神虚透：本是「欲发不能」，运岁填实则祸发——此即「虚实颠倒生祸」。
- 反例：把「忌神虚透故今年无事」当成常量，忽略该年正好给了它实根，会把凶年断成平年。
- 出处：[12.4]

**规则**：两个固定刻度——晚年禄神到位多主寿险；墓神到位主收藏、封存、旧事重提。
- 判据：寿元星（禄、食神一类）在晚运被填实又被冲，按寿险断，不按发财断。
- 出处：[12.4]

## 六、把原局结构落到某一年的操作顺序（13.1）

**规则**：按以下六步走，不许跳步。
1. 定原局做功组合与功神（见 R14 七步法第 1–3 步）。
2. 列出该做功组合的「待发条件」：有合待冲、有冲待合、有墓待冲、有绝待生。
3. 查大运是否到位或引发：运字＝原局某字/原身/禄神 → 兑现；运字冲合刑穿该组合 → 引发。同时用分统诀确定本运是否切分。
4. 查流年三法：出现、引动、干支互应，锁定到具体某一年。
5. 定吉凶：只看被引动、被填实之字是喜用还是忌仇。喜用被合来、合动、冲起 → 吉；喜用被合去、合绊、冲破 → 凶；忌仇反之。
6. 复核层次：原局本无功、或功神无根者，运岁再热闹也只是小动静，不上大结论。
- 出处：[13.1] [12.2] [12.3] [13.3]

## 七、岁运并临 / 征太岁 / 晦太岁（13.2）

**规则**：岁运并临＝大运干支与流年干支完全相同。断法三步，顺序不可颠倒。
1. 辨喜忌：并临之字是喜用 → 吉加倍；是忌仇 → 凶加倍。
2. 观作用：并临之字是否冲克命局关键喜用。冲了喜用 → 凶烈，这是并临最怕的形态。
3. 察宫位：该字落在哪一柱，即定六亲与领域（年柱长辈、月柱父母兄弟事业、日柱自身配偶、时柱子女晚年）。
- 反例：只说「岁运并临不死自己也死亲人」——书上无此绝对断法。并临只是把该字力量放大一倍，吉凶仍由喜忌决定。
- 出处：[13.2]

**规则**：征太岁＝大运主动冲克流年太岁，属以下犯上。
- 主突发、对抗性灾祸：官非、刑狱、车祸、争斗，来得急、有对抗方。
- 辨方向：运冲年为「征」，祸由己方挑起或己方受损；年冲运为「受冲」，多为外来冲击。
- 看十神：伤官、七杀、劫财冲岁，祸烈；正官、正印冲岁，稍轻，多主变动、离职、调岗。
- 察五行：金木战 → 筋骨外伤、车祸；水火战 → 心血、火灾、口舌；土土冲 → 脾胃、房产土地、阻滞。
- 判据：运强岁弱，祸尤烈；运弱岁强，多主被动受制而非大灾。
- 出处：[13.2]

**规则**：晦太岁＝阴性忌神势盛，把阳性太岁的光气晦掉。
- 构成：湿土（辰、丑）、寒水（亥、子）、重金（申、酉）成党势盛，围压太岁之阳气（丙丁、巳午）或生机（甲乙、寅卯）。
- 判据：阳性太岁被阴性五行包围且无火来通关、无木来疏土。
- 应事特征：**缓**。运势渐衰、慢性病、暗耗、贵人远离、名声渐暗；重则寿元。与征太岁的「急、烈」正相反，两者不可混断。
- 出处：[13.2]

## 八、天合地合 / 天克地冲（13.3）

**规则**：判断合冲先分对象，对象不同，性质不同。
- 流年合大运 → 合动（引动该运之气，提前发用）。
- 流年合命局 → 合绊或合留（引动命局本身之事）。
- 大运合命局 → 合绊（长期牵制该字，十年使不上力）。
- 另分明暗：合来＝合入，主得到；合去＝合出，主失去。
- 出处：[13.3]

**规则**：天合地合＝运或岁的干支与命局某一柱的天干五合、地支六合同时成立。该柱被整体绊住。
- 判据：被绊之柱若是喜用 → 该领域十年或一年使不上劲（如食神被绊则表达、自由、子女之事受制）；若是忌神 → 被绊住反为吉，忌神暂时不能为害。
- 出处：[13.3]

**规则**：天克地冲＝运或岁的干支与命局某一柱天干相克、地支相冲同时成立。该柱被连根拔起。
- 判据：被冲克之柱是喜用 → 大凶，主破格、破财、伤身、寿终；是忌神 → 大吉，忌神连同其根一并去掉。
- 加凶条件：该柱又与日柱、时柱伏吟（同柱重现），凶上加凶。
- 出处：[13.3]

**规则**：冲分四种，按力量对比定性质。
- 力量相当 → 冲动（变动、迁移）。
- 弱被强冲 → 冲去（去掉、离场）。
- 冲开库墓 → 冲开（发、得权）。
- 冲坏喜用 → 冲破（灾）。
- 力度差别：大运冲命局力强，可致冲破；流年冲命局多为冲动、引动。流年冲大运时，正行干运为冲动（提前引动该干之事），正行支运为冲去（减弱该支之力）。
- 出处：[13.3]

**规则**：合冲本身没有吉凶，唯一标准是「所合所冲之字是喜用还是忌仇」。
- 喜用被合来、合动、冲起 → 吉；喜用被合去、合绊、冲破 → 凶。
- 忌仇被合去、被冲去 → 灾消；忌仇被冲起、被填实 → 祸萌。
- 判据：任何一条合冲结论，必须能指出「被作用的那个字在原局是喜是忌」，指不出就是没判。
- 出处：[13.3]

**规则**：合冲反局是最凶的一类，指岁运的合冲破坏了原局固有的做功组合。
- 形态一：原局靠合来制，岁运来冲坏这个合 → 制力全失。
- 形态二：原局靠冲来制，岁运来合解这个冲 → 冲力被卸。
- 后果：破格、破财、伤身、寿终。运过之后结构可恢复，但事件已经发生。
- 判据：先确认原局的做功确实建立在某一组合之上（该合/该冲是功神而非闲神），再判反局。原局本无此功者，不成反局。
- 出处：[13.3]

## 判错清单

- 用「流年干支是喜用就吉」直接定吉凶——原文点名此为误区；流年只司应期，吉凶要回原局做功里取。
- 大运该统看时仍分看（流年与大运天干五合、或地支相冲、或运干支一气），把十年断成两截。
- 虚透之字在运岁出现就当大事断：虚神只是信号，须先查是否被填实（禄神/原身/同类实根）。
- 只报「并临」「冲太岁」的名目，不辨喜忌、不查被冲之字是喜是忌——名目本身不含吉凶。
- 把晦太岁（缓、暗耗、渐衰）与征太岁（急、突发、对抗）混作一类断，应事节奏与严重度全错。
- 见冲就断凶、见合就断吉，不区分合留/合动/合去/合绊与冲动/冲去/冲开/冲破。
