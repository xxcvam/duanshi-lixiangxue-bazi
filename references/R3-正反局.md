# R3 正局与反局

> 覆盖节号：3.1 正局 / 3.2 反局 / 3.3 运岁反局
> 加载时机：做功结构已定，需要判定此盘是顺（正局）还是逆（反局），或判断大运流年是否把原局结构打反时加载。

## 一、正局

**规则**：正局＝日主（或日支）想要的，正是全局党势正在做的那件事。两条同时成立才算，缺一条不算。
- 判据一「意向明确」：日干有合或冲，或日支有合、冲、刑、穿、墓，指向一个具体十神（财／官／印／食）。
- 判据二「趋势一致」：全局党势的做功方向（制、化、合、墓）与这个对象同一，且真能达成。
- 例外一：干无合冲、支无合冲刑穿 → 无明确意向。此为「无功」，既非正局也非反局，不得因「五行流通顺畅」判成贵格。
- 例外二：意向明确但局势与之无关（各做各的）→ 亦不成局，只论功神大小，不论顺逆。
- 出处：[3.1]

**规则**：取向意按三级顺序，判到哪级够用就停。
- 判据：一级不成立才看二级，二级不成立才看三级；取第一个成立者，不叠加。
- 一级（日主干）：日干合财 → 求财；合官 → 求管理、控制、名位；合印 → 求庇护、学历、单位。最常见，也最容易被误判。
- 二级（日支）：日干无合冲时才看日支。日支合财 → 求财，且多由婚配、家庭带来；日支为墓库 → 求「收藏、控制」；女命日支合夫星 → 求夫。
- 三级（干支同向）：日干与日支同时做功且方向相同 → 最理想，成就上限最高。
- 注意：三级是优先次序，不是等级高低。二级正局一样能成巨富（[3.1] 例四）。
- 出处：[3.1]

**规则**：「功神到位」＝做功的那个字在原局已成实，并与做功对象正面接触。
- 判据：三条同时成立才算到位 ——①功神有根（坐禄、刃、长生，或本气即其五行）；②功神与对象有直接的合／冲／刑／穿／墓，不是隔位空喊；③功神自身不被合绊、穿坏、冲散。
- 不到位：功神虚透无根、与对象之间被别的字合走或制断、自身被绊 → 功不成，层次降等，或改以他象论。
- 正例：乙巳 己丑 壬辰 辛丑，功神是日支辰墓（官杀库）；丙戌运戌冲辰，库开，功神被引动，五年发数亿 [3.1]。
- 反证：同一造行乙运，乙木透出受辛金克，等于辰墓这个功神被破，癸未年因非法集资被捕、判二十年 [3.3]。
- 出处：[3.1] [3.3]

**规则**：正局既成，层次由四件事定。
- 判据：四件事逐项打分，四项皆高者上格，缺项按最低一项定档。
- ①功神效率：合制、库冲、围克这类「一次做尽」的方式，高于反复摩擦式做功。
- ②气势大小：成党成势者格局高、做功影响面大；单字做功只能小成。
- ③功神协同：多种做功方式指向同一目标（复合结构）→ 多领域建树、资源整合力强。
- ④运岁顺局：行运继续强化原局之势、补足功神 → 成就再上一档。
- 出处：[3.1]

**正局案例**（四柱 → 结论 → 机制）
- 庚子 丙戌 壬申 丙午（乾）｜巨富，房地产商｜壬合时干丙财，申子半合助身、戌午半合助财，局中无物破这个合。
- 戊申 己未 癸巳 己未（乾）｜巨富，股市庄家｜癸合年干戊官，火土燥势制申金劫财；合官之「管理」与制劫之「取财」同向。
- 己酉 丁卯 庚戌 己卯（乾）｜企业家，得妻财兴家｜日支戌合双卯财，卯冲酉、戌脆酉，制劫护财与日支求财同向。
- 乙巳 己丑 壬辰 辛丑（乾）｜巨富，墓库收用｜两丑官星（当财看）与巳财尽入日支辰库，库即功神，运冲即发。
- 壬寅 丙午 戊寅 乙卯（乾）｜政府官员，正处级｜丙火印星化木杀生身，木生火、火生土，印化杀与日主依托印星之意向合一。
- 癸巳 甲子 癸卯 丙辰（坤）｜私营企业主，技术起家｜日支卯食神生时干丙财，甲木伤官亦生丙，水木火一路流通。
- 丁未 壬子 丙申 甲午（乾）｜军官｜时支午刃制月令子杀，丙火喜壬杀煅炼，刃与杀各得其位。
- 甲寅 癸酉 丁丑 庚子（乾）｜企业高管，管理、业务、外交皆通｜日支一丑同时合印（酉）、合财（子），多合用协同为一。
- 壬午 辛亥 庚辰 丁亥（乾）｜学术成就极高｜金水伤官配印，行水木运助伤官，顺局加分。

## 二、反局

**规则**：反局是正局的方向取反，条件结构相同，方向相反。
- 判据一：有意向（日干合冲，或日支合冲刑穿墓）。
- 判据二：趋势相反 —— 党势正在制克、破坏该对象；或日干与日支的意向本身互相矛盾。
- 前置闸：先确认「有意向」。无意向之盘不判反局，判「无功」或「清浊」。这一步漏掉，会把平庸之命判成凶命。
- 出处：[3.2]

### 类型一 日主所求，正被局制（最凶）

**规则**：日干合某物，而全局党势正在制克该物、或制克日主自身 → 反局。
- 判据（三条任一即成立）：
  1. 日主合官，局中杀旺且无制化 → 官非牢狱。
  2. 日主合财，局中比劫成党劫夺 → 破财刑伤。
  3. 日主合的东西反过来生助克身之神（合财生官杀克身）→ 贪财引杀。
- 灾祸面：牢狱、官非、重大伤病、暴死、一生困顿潦倒。
- 例外：局中虽制所合之物，但制它的字无根或被绊、制不动 → 不作反局，作「有惊无险」或半成。
- 出处：[3.2] 法则一
- 己巳 壬申 己未 乙丑（乾）｜终身坐牢｜己合壬财却置身两党交战，时干乙杀坐丑直克日主，丑未冲又冲掉日主之根。
- 戊申 丁巳 辛亥 甲午（乾）｜县长起家，终被枪决｜辛合甲财，甲木生巳午之火反克辛金，求财之举等于自增杀源。

**规则**：反局之命不等于立刻见凶，须运岁引爆；引爆前往往还有一段顺境。
- 判据：原局之凶只决定「凶的方向」，不决定「何时」。运岁顺了凶神则暂时升迁，运岁回来才应灾。
- 反例警示：上造行丙寅运，寅午戌合火、去亥水之忌而升官；卯运合戌破火局而丢官；戊辰运辰戌冲开火库，酉年禄被合穿而亡。
- 出处：[3.2]

### 类型二 日支所求，正被局制

**规则**：日干无合冲时看日支；日支合的是局中正在制的东西 → 反局。
- 判据：日支合财而局中比劫制财；日支合官杀而局中食伤或燥土制官杀；日支合印而局中财星坏印。
- 灾祸面：婚姻破裂、配偶灾殃、家庭拖累、因家事败业。
- 出处：[3.2] 法则二
- 丙子 戊戌 丁丑 丁未（坤）｜夫早亡（车祸），三子皆残疾，一生穷困｜日支丑合子水夫星，全局戌未燥土正制子水与丑中之金水，求夫与制夫相反。
- 癸未 丙辰 戊戌 丙辰（乾）｜一生穷困，年入最多千元｜日主合癸财，而日支戌（自身之根、火库）被月时双辰冲克，财反坏其体。

### 类型三 日干与日支各求相反（内在反局）

**规则**：天干合的对象，与地支合／冲的对象互为仇敌 → 内在反局。
- 判据：日主合财而日支劫财夺财；日主合官而日支伤官克官。必须指出天干、地支两个具体相反动作，不能凭「感觉矛盾」。
- 灾祸面：精神困扰、决策失误、婚姻反复、多成多败、心口不一。
- 原文状态：本法则原文未给确证案例，所附「典型例」原文自标「（假设）」（甲午 癸酉 戊子 壬戌），不得当实例引用。
- 出处：[3.2] 法则三

### 类型四 冲合并见（结构自反）

**规则**：年月柱以合做功、日时柱以冲做功（或反之），两种相反动作并存且各不解救 → 结构自带反局。
- 判据：年月见合（如巳申合）同时日时见冲（如丑未冲、子午冲）；两组动作各自成立。
- 灾祸面：一生动荡、虎头蛇尾、人际极端复杂、常陷是非、易有牢狱。
- 出处：[3.2] 法则四
- 己巳 壬申 己未 乙丑（乾）｜终身牢狱（与类型一同盘双断）｜年月巳申合、日时丑未冲，一边合取、一边冲夺，手段自相矛盾。
- 戊申 丁巳 戊子 戊午（乾）｜一生极贫，干苦力，年入微薄｜年月巳申合、日时子午冲；子财被午冲、被巳绝，而申巳合中又生申生子，财星处境自相矛盾。

### 补充型五 连体之体被局中功神制（体用对抗）

**规则**：日主与其根、其印连成一体，而局中党势正制这个连体 → 反局，伤及自身。
- 判据：连体（同气柱，或印—身—根三字相贯）被制，且制它的党势有根、到位。
- 应期：看被制之字何时到位（流年或大运引其字）。
- 灾害面：伤残、暴死。
- 例外：体被制而体有救（印化、比劫帮、制神无根）→ 不作反局，只作压力。
- 出处：[3.2] 附案例八
- 壬寅 戊申 辛巳 戊戌（乾）｜电工，壬申年触电亡｜辛、申（根）、戊（印）连为一体，寅巳戌木火成势制申金；壬申年申到位而被制。

### 补充型六 包局带忌（一点被坏）

**规则**：全局一边倒（如阴湿成势），唯一一点相反之气被穿坏、耗干、克去 → 反局。
- 判据：局中仅存一阳、一燥、一个用神，被党势穿坏或耗竭。
- 灾祸面：失权、被困、慢性困顿，未必见血。
- 出处：[3.2] 附案例九
- 庚子 戊子 乙卯 癸未（乾）｜壬辰运抗日有功，癸巳运被软禁三十余年｜水木阴湿成势，独时支未土一点燥气被子未穿坏；癸巳运癸透克戊财、巳火被子水克，用神全失。

### 凶在什么事，由对抗焦点定

**规则**：反局只定「凶」，凶在哪一类事，看被逆的是什么神。
- 判据：灾祸面由被逆之神的类别定，按下面四条取。
- 官杀、羊刃、亡神劫煞被逆 → 官非刑狱、血光横死。
- 财星被逆 → 一生贫贱、求财艰难、因财生祸。
- 对抗双方势均力敌 → 伤残、生死大灾、长期牢狱；一方明显无力 → 只主困顿潦倒。
- 出处：[3.2]

## 三、运岁反局

**规则**：运岁反局＝原局本有隐患，运岁把它点着。两条同时成立。
- 判据一（静体）：原局有隐患 —— 制而不净、包局带忌、忌神伏藏，或已成正局但有一处未经处理。
- 判据二（动因）：运岁以合、冲、刑、穿、墓，破坏功神／改变做功方式（冲变合、合变冲）／扶起忌神对抗用神。
- 例外：原局本身已是反局者，运岁再反只加凶，不另立「运岁反局」；清纯无功之局最怕运岁把伏藏之忌神引出来。
- 出处：[3.3]

### 大运三型

**类型一 破坏功神**（最直接凶险）
- 识别：运字一字多能 —— 同时穿功神、晦用神、生忌神，三者齐发即全面反局。
- 判据：运字与功神构成穿／冲／合绊，且该运字五行生助原局被制之神。
- 戊申 甲寅 辛卯 癸巳（乾，薄一波）｜丙辰运坐牢五年｜辰穿卯（功神）、晦巳（制申之神）、生申（忌神），辰又为伤官库带牢狱象。
- 己未 癸酉 丁巳 丁未（乾，袁世凯）｜庚辰运贬职，闲居青岛五年｜辰晦巳、辰酉合护住酉金忌神、辰为水库生癸杀。
- 例外：运字只伤功神之一、其余功神仍在 → 只主波折，不主十年困顿。

**类型二 改变做功方式**（冲变合、合变冲）
- 识别：原局以冲做功，运来合；原局以合做功，运来冲；或运来合闭墓库，使原局已开之库重新关闭。
- 判据：运字与原局做功的那一对字构成相反动作，且运字本身有根（虚字合不动）。
- 庚申 己丑 丙申 乙未（乾）｜辛卯运，父欠债自杀｜原局两申入丑、以丑未冲做功；卯合申，把「冲」改成「合」，父星被合住。
- 癸卯 乙丑 辛未 己丑（坤）｜壬子运己卯年破大财、死一女｜原局丑未冲开财库；子合丑则库闭，冲的做功失效。

**类型三 伏吟、三刑自刑**
- 识别：运干支与原局某柱伏吟（重复），或与原局组成三刑、自刑。
- 判据：伏吟须伏在「有功之柱」上才凶；伏吟无功之柱只主重复、拖延。
- 乙巳 己丑 壬辰 辛丑（乾）｜乙运首年癸未被捕，判二十年｜乙伏吟年干成伤官见官，且乙为辰墓之透出，乙被辛克即辰墓功神被破。
- 原文状态：本例原文在「乙庚相合」处自打问号，推演不完整；只采「伏吟＋伤官见官＋功神被破」三条判据，不引其细节。

### 流年两型

**类型一 流年单独引动**
- 识别：流年一字冲／合／穿到功神或忌神，即使大运平顺也成反局。
- 判据：流年改变了原局做功的动作类型（穿变合、合变冲），或把忌神补成有根。
- 癸卯 丙辰 戊子 丙辰（乾）｜甲申年被审查、关押三月、丢官｜原局辰穿卯制官；申年申子辰三合、申卯暗合，把「穿」改成「合」，反护住卯官。
- 辛卯 丙申 辛未 丁酉（乾）｜丁卯运乙酉年枪毙｜卯酉冲，酉（禄刃）冲动卯财，引动原局丁火七杀攻身。

**类型二 岁运天地合，或岁运三刑**
- 识别：流年与大运天合地合；或流年补成三刑、双冲。
- 判据：天地双合把原局正在相冲的两党一起锁死 → 最凶；三刑把原局单一高效的刑制搅成混战 → 次凶。
- 癸卯 乙丑 辛未 己丑（坤）｜己巳运甲申年车祸，脊柱断裂成植物人｜甲己合、巳申合，天地双合锁住丑未相冲的两党；申主筋骨、甲主头，皆被合绊。
- 丙午 辛丑 戊戌 戊午（乾）｜癸未年入狱一年｜未与原局丑戌凑成丑未戌三刑，搅乱原局「戌刑丑」的单一做功，无事生非。

### 应期五条

- 原局定性先于运岁：正局与清格怕反局运岁；原局已反者一生多舛，运岁再反更凶。
- 运看十年趋势，年看具体应期；大运反局期中必有流年引爆，流年反局若大运亦凶则加倍。
- 合冲互变是最常见的反局信号，优先查。
- 重点宫位：禄、刃被冲穿合 → 身体灾祸；墓库被合闭或刑开 → 事业财物巨变；夫妻宫、子女宫被破 → 六亲灾咎。
- 贼捕原理：原局制得干净，最怕运岁让被制之神得根助旺；原局制不干净，最怕运岁把制神合绊无力。
- 出处：[3.3]

**补充两例（3.3 附）**
- 庚申 戊寅 丁未 庚子（乾，抗日名将）｜辛巳运之巳运失势｜巳申合解了原局寅申冲，把功神申金合绊，反助金水。
- 戊戌 甲寅 丁卯 甲辰（乾，周恩来）｜乙亥年肝脓肿重病、军权被夺｜亥从辰中出，亥卯合住功神卯木，反保护辰土忌神。原局以穿做功者，最怕合来改。

## 判错清单

1. 意向没定就判反局：干无合冲、支无合冲刑穿是「无功」，不是「反局」。
2. 只看天干不看党势：日主合财就断富，没查比劫是否成党夺财 —— 合财被劫即反局。
3. 把「体被制」一律当反局：体有救（印化、比劫帮、制神无根）只是压力；只有连体被制、体用对抗才是反局。
4. 运岁见合断吉、见冲断凶：原局以冲做功最怕合，以合做功最怕冲，冲合互变本身即信号。
